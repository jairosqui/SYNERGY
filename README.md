# Synergy Advisory Consulting — sitio web

Sitio estático (HTML/CSS/JS), sin build.

## Deploy en Vercel
- **Directo:** `vercel` desde esta carpeta, o arrastre la carpeta en vercel.com/new. Framework Preset: *Other*; sin Build Command ni Output Directory.
- **Con GitHub:** suba esta carpeta a un repo, impórtelo en Vercel y deje Root Directory en la raíz del repo (o en `site`).

## Pendientes
1. **Formulario:** en `contacto.html` reemplace `TU_ACCESS_KEY_AQUI` con su clave de Web3Forms (web3forms.com, la clave define el correo destino).
2. **Teléfono y correo:** busque los comentarios `Agregar` en `contacto.html` y el pie de página.
3. **Dominio:** añada `sitemap.xml` y la línea Sitemap en `robots.txt`.
4. **Fotografías:** use solo imágenes con licencia o propias; colóquelas en `assets/`.
5. Revisión legal de `privacidad.html` y `terminos.html`.
